Installation
============

Requirements
------------

- **Moodle**: 4.3 or higher (minimum required version `2023100400`)
- **PHP**: 8.1 or higher

Installation Procedure
----------------------

1. Access your Moodle installation's course formats directory:

   .. code-block:: bash

      cd /path/to/moodle/course/format

2. Clone the repository naming the folder `timeline`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/format_timeline.git timeline

3. Access the notifications area in Moodle as an administrator to perform the database table upgrades.
