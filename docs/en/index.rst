Overview - moodle-format_timeline
==================================

**moodle-format_timeline** is a course format for Moodle that simulates a modern social network timeline, making activity and content navigation more interactive and engaging.

Key Features
------------

- **Timeline Visuals**: Chronological presentation of course modules and activities.
- **Social Interaction**: Feed-inspired layout with posts and comments.
- **Compatibility**: Full support for Moodle 4.3 and higher.
