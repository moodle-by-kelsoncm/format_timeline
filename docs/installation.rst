Instalação
==========

Requisitos
----------

- **Moodle**: 4.3 ou superior (versão mínima exigida `2023100400`)
- **PHP**: 8.1 ou superior

Procedimento de Instalação
--------------------------

1. Acesse o diretório de formatos de curso da sua instalação Moodle:

   .. code-block:: bash

      cd /caminho/do/moodle/course/format

2. Clone o repositório nomeando a pasta como `timeline`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/format_timeline.git timeline

3. Acesse a área de notificações no Moodle como administrador para efetuar a atualização das tabelas de banco de dados.
